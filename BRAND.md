# CGSA Visual Identity

Chemistry Graduate Students' Association — University of Calgary

## Logo

`assets/cgsa-logo.svg` — black & white wordmark: a periodic-table "Carbon" element
block forming a large "C," paired with "Chemistry Graduate Students' Association"
and an Erlenmeyer flask icon.

## Color Palette — "Flame Test"

Inspired by flame test colors from analytical chemistry (Li = red, Ca = orange,
Na = yellow, Cu/Ba = green) — a direct, on-brand tie to the department.

| Name          | Hex       | Use                                  |
|---------------|-----------|---------------------------------------|
| Flame Red     | `#E4572E` | primary accent, CTAs, links           |
| Ember Orange  | `#F79824` | secondary accent, hover states        |
| Flame Yellow  | `#F7C548` | highlights, tags, small accents       |
| Bunsen Green  | `#4C9F70` | success/confirm states, secondary CTA |
| Ink           | `#231F20` | text, matches logo fill               |
| Paper         | `#FAF8F5` | background                            |
| Slate         | `#6B6864` | muted text, captions                  |

Use the four flame colors sparingly as accents against Ink/Paper — not as
large color blocks. Think Bunsen-flame gradient (red → orange → yellow) for
hero accents/dividers, green reserved for confirmation/success moments.

## Typography

Logo wordmark uses a rounded slab-ish sans (reads like Open Sans) — **not used
site-wide**, it's for the mark only.

- **Display (h1/h2, element-tile C):** Lastik — characterful display face,
  single 400 weight (free cut), self-hosted at `assets/fonts/`. Never
  synthesize bold.
- **Body + subheadings:** Satoshi — variable weight 300–900, self-hosted at
  `assets/fonts/` (normal + italic).
- **Accent/mono:** JetBrains Mono — for small tags like the "6 / Carbon /
  12.011" element-block detail, atomic numbers, or event dates styled like
  periodic table cells. Loaded from Google Fonts.

## Logo Usage Note

Current logo file is black & white only. Recommend an all-Ink version for
light backgrounds (as-is) and consider a Paper/white version for dark or
Flame Red backgrounds — Fable should produce this as an SVG color variant.
